Nilai Budaya Minahasa

Kearifan lokal untuk pencegahan PTM

Si Tou Timou Tumou Tou
"Manusia hidup untuk memanusiakan manusia lainnya"

Nilai ini mengajarkan bahwa setiap anggota keluarga memiliki tanggung jawab untuk saling menjaga kesehatan.

  • Mengingatkan anggota keluarga untuk memeriksa kesehatan secara rutin
  • Membantu anggota keluarga yang sedang menjalani pengobatan PTM
  • Menemani lansia berolahraga
  • Mengingatkan jadwal kontrol ke fasilitas kesehatan
  • Memberikan dukungan emosional
Mapalus
"Semangat bekerjasama dan saling membantu demi kepentingan bersama"
  • Senam bersama di lingkungan desa
  • Jalan sehat rutin
  • Kerja bakti membersihkan lingkungan
  • Kebun keluarga untuk menanam sayur dan tanaman obat
  • Posbindu/Posyandu PTM berbasis masyarakat
  • Saling mengingatkan pola hidup sehat
Torang Samua Barsaudara
"Semua orang adalah saudara"
  • Membantu lansia mengikuti pemeriksaan kesehatan
  • Mengajak tetangga mengikuti skrining PTM
  • Berbagi informasi kesehatan yang benar
  • Mendukung anggota masyarakat yang sedang menjalani pengobatan
Musyawarah & Kebersamaan Keluarga
"Keluarga berperan penting dalam mengambil keputusan"
  • Menyusun menu sehat bersama
  • Menentukan jadwal olahraga keluarga
  • Mengurangi konsumsi makanan tinggi garam, gula, dan lemak
  • Menetapkan hari tanpa minuman manis
  • Membuat target kesehatan keluarga
Menghargai Alam sebagai Sumber Kehidupan
"Hubungan erat masyarakat Minahasa dengan alam"

Pangan sehat lokal: Gedi, daun pepaya, pakis, ubi jalar, talas, jagung, pisang goroho, ikan laut segar, rempah-rempah lokal, TOGA.

  • Mengurangi konsumsi makanan ultra-proses
  • Meningkatkan asupan serat
  • Membantu mengendalikan tekanan darah, gula darah, dan kolesterol
Tradisi Berkebun
"Aktivitas fisik yang menyehatkan"
  • Menurunkan risiko obesitas
  • Mengendalikan tekanan darah
  • Menurunkan kadar gula darah
  • Mengurangi stres
  • Menjaga kebugaran tubuh
  • Menyediakan bahan pangan sehat
Kebersamaan dalam Makan
"Makan bersama bagian dari budaya Minahasa"
  • Menyajikan menu tradisional yang lebih sehat
  • Mengontrol porsi makan
  • Menambah konsumsi sayur dan buah
  • Mengurangi makanan tinggi garam dan lemak
  • Menjadi sarana edukasi kesehatan bagi anak
Disiplin & Tanggung Jawab
"Sikap disiplin dan tanggung jawab dalam budaya Minahasa"
  • Minum obat sesuai anjuran
  • Pemeriksaan kesehatan rutin
  • Berolahraga
  • Mengatur pola makan
  • Tidur yang cukup
  • Berhenti merokok
  • Membatasi konsumsi alkohol

📋 Panduan Setup Google Sheets

Ikuti langkah-langkah berikut agar data bisa tersimpan:

Langkah 1: Buka Google Apps Script

Dari spreadsheet Anda, klik Ekstensi → Apps Script

Langkah 2: Paste Kode Berikut

Hapus semua kode lama, lalu paste:

function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(30000);

  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getActiveSheet();

    // Setup header otomatis
    if (sheet.getLastRow() === 0 || sheet.getRange(1,1).getValue() !== 'Timestamp') {
      var headers = ['Timestamp','Nama','Umur','Jenis Kelamin','IMT',
        'Tekanan Darah','Gula Darah','Risiko Umum','FACE','Jantung',
        'Diabetes','Kanker','Rekomendasi'];
      sheet.getRange(1,1,1,13).setValues([headers])
        .setFontWeight('bold').setBackground('#4285f4').setFontColor('#ffffff');
      sheet.setFrozenRows(1);
      sheet.autoResizeColumns(1,13);
    }

    sheet.appendRow([
      new Date(),
      data.nama || '',
      data.umur || '',
      data.kelamin || '',
      data.imt || '',
      data.tekananDarah || '',
      data.gulaDarah || '',
      data.risikoUmum || '',
      data.face || '',
      data.jantung || '',
      data.diabetes || '',
      data.kanker || '',
      data.rekomendasi || ''
    ]);

    lock.releaseLock();

    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      row: sheet.getLastRow(),
      message: "Data berhasil disimpan"
    })).setMimeType(ContentService.MimeType.JSON);

  } catch(err) {
    lock.releaseLock();
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput(JSON.stringify({
    status: "ok",
    message: "Web App SMART PKK aktif!",
    timestamp: new Date().toISOString()
  })).setMimeType(ContentService.MimeType.JSON);
}

Langkah 3: Deploy Web App

  1. Klik Deploy → New deployment
  2. Pilih type: Web app
  3. Description: SMART PKK Web App
  4. Execute as: Me
  5. Who has access: Anyone ← PENTING!
  6. Klik Deploy
  7. Salin URL Web App yang muncul

Langkah 4: Update URL di Aplikasi

Ganti URL di file HTML dengan URL baru dari deploy:
